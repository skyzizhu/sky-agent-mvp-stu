
## 21:37:32
Apple 开发者账户价格核实：
- Apple Developer Program：99 美元/年；中国区官方帮助页显示「以每年 ¥688 续订」（developer.apple.com/cn/help/account/membership/enrolling-in-the-app）。
- Apple Developer Enterprise Program：299 美元/年，面向企业内部私密分发（developer.apple.com/cn/programs/）。
- 免费开发者账户（仅需 Apple ID）：可下载 Xcode/模拟器、真机自测，但不能上架 App Store、不能用 TestFlight 外部测试，自签 App 每 7 天过期需重装（pintech.com.tw、developer.apple.com 帮助页）。
- 苹果仅按年计费，无官方月付选项；用户问的"一个月"需按年费换算。99USD/12≈8.25USD/月；688元/12≈57.3元/月。Enterprise 299USD/12≈24.9USD/月。
