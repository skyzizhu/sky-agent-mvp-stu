# 07 原型标注集（工作台界面截图 + 逐元素标注）

> **给谁看**：研发（实现界面）、新人（认识产品） ｜ **什么时候用**：界面开发、改版对照、交接培训
> **一句话**：已上线的界面就是最高保真原型——每张截图标注「这个元素的数据从哪来、四种状态各显示什么」。

## 图 1 首页全景（assets/ui-01-首页全景.png）

| 元素 | 数据来源 | 交互说明 |
|---|---|---|
| 页头预算仪表 | 每 final 事件更新 used/max | 档位切换时清零 |
| 运行历史列表（左栏） | GET /api/runs 倒序 | 点击任意条目 → 进入该会话回放 |
| 执行流面板（中区） | SSE 事件流逐颗粒渲染 | 颗粒可展开；顶部「展开全部」一键开合 |
| 场景词 chips | 前端静态 | 点击填入问题并联动切档位 |
| 输入区 + 档位按钮 | 本地状态 | Ctrl/⌘+Enter 提交；运行中禁用 |

## 图 2 执行流颗粒展开（assets/ui-02-执行流颗粒展开.png）

| 元素 | 标注 |
|---|---|
| 分组卡片「第 N 步」 | 按 step 编号分组折叠，步内动作自动编号 N.M |
| 模型调用颗粒 | 展开三区块：① 完整输入（messages 全量）② 模型全字段输出 ③ token 明细（输入/输出/思考/缓存） |
| 工具颗粒 | 参数 + 完整输出 + ⏱ 耗时；徽章：⚡ 缓存命中 / 📄 萃取提纯 / 🌐 JS 降级 |
| 回填确认颗粒 | 本轮全部 tool_call_id 配对结果（一圈一结清） |
| 看板注解 | 卡片内固定一行架构说明：子问题由主 agent 串行核销，无并行子 agent |

## 图 3 报告面板（assets/ui-03-报告面板.png）

| 元素 | 标注 |
|---|---|
| 元信息行 | 约 X 字 · 耗时 Ys · 消耗 Z tok（来自 final 事件） |
| MD 渲染区 | 前端先 DSML 净化再转义再 marked 渲染；链接新窗口打开 |
| 复制 MD / 下载 .md | clipboard API，非安全上下文 execCommand 兜底 |
| ⛶ 全屏阅读 | zen 模式，Esc 退出 |
| 显隐规则 | 无有效报告时整个面板隐藏 |

## 图 4 任务核销看板卡片（assets/ui-04-看板卡片.png）

| 元素 | 标注 |
|---|---|
| 架构说明行 | 固定注解：子问题由主 agent 串行核销，无并行子 agent |
| 进度条 + 统计 | N/M 已核销 (%)，checklist 事件驱动 |
| 子问题条目 | ⚪ 待查证 / ⏳ 查证中 / ✅ 已完成 + 结论摘要（来自核销依据） |
| 同源原则 | 与模型每轮看到的进度注入是同一份状态 |

## 截图更新规范

界面改版后必须重截对应图并更新本文件标注。截图方法：浏览器打开工作台 → 回放一次运行 → 按需展开颗粒/面板 → 截图存入 assets/。
