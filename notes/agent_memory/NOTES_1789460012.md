deepseek-flash：输入(缓存命中) off-peak $0.003 / peak $0.006；输入(缓存未命中) off-peak $0.15 / peak $0.3；输出 off-peak $0.6 / peak $1.2。

【扣费规则】费用 = tokens 数 × 单价；直接从充值余额或赠送余额扣除，两者都有时优先扣赠送余额。价格可能调整，建议按实际用量充值并定期查看该页。

【子问题3-限流/并发】官方 Rate Limit 页 (api-docs.deepseek.com/quick_start/rate_limit)：
- 并发上限(账户级，与用哪个API Key无关)：deepseek-flash=2500，deepseek-v4-pro=500。
- 请求从发出到响应完成算一个并发连接；超限返回 HTTP 429。
- 可提交扩容申请，按业务需求匹配并发，扩容不额外收费。
- user_id 参数用于内容安全隔离、KVCache 隔离、调度隔离；普通用户所有 user_id 合并计算并发；扩容用户对每个 user_id 也单独限流(flash 2500 / pro 500)。
- 保活：非流式持续返回空行，流式返回 ": keep-alive" 注释；若请求 10 分钟未开始推理，服务器关闭连接。
【错误码】400 格式错误、401 鉴权失败、402 余额不足、422 参数无效、429 触发限流、500 服务器错误、503 服务器过载。来源：api-docs.deepseek.com
