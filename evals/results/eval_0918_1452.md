# DeepSeek API 模型与定价 · 阶段性结题报告

## 一、已确认的发现

### 1. 当前官方在售模型（仅两个）

官方「模型 & 价格」页当前仅列出 `deepseek-flash` 与 `deepseek-v4-pro` 两个模型 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。

| 项目 | deepseek-flash | deepseek-v4-pro |
|---|---|---|
| 模型版本 | DeepSeek-V4.1-Flash | DeepSeek-V4-Pro-0813 |
| 上下文长度 | 1M | 1M（同栏合并说明） |
| 输出长度 | 最大 384K | 最大 384K（同栏合并说明） |
| 输入·缓存命中·空闲 | 0.02 元 | 0.15 元 |
| 输入·缓存命中·高峰 | 0.04 元 | 0.30 元 |
| 输入·缓存未命中·空闲 | 1 元 | 4.5 元 |
| 输入·缓存未命中·高峰 | 2 元 | 9.0 元 |
| 输出·空闲 | 4 元 | 13.5 元 |
| 输出·高峰 | 8 元 | 27.0 元 |
| 并发限制 | 2500 | 500 |

（单位为元/百万 tokens；上表所有数字逐字来自官方页面原文 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)）

- BASE URL：OpenAI 格式 `https://api.deepseek.com`，Anthropic 格式 `https://api.deepseek.com/anthropic` [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)
- 计费时段：空闲时段价格为高峰时段价格的一半；高峰时段为北京时间周一至周五 9:00–12:00、14:00–18:00，其余为空闲时段 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)
- 功能支持：Json Output、Tool Calls、Responses API、Anthropic API、对话前缀续写（Beta）两者均支持；FIM 补全（Beta）仅非思考模式支持；图像理解仅 `deepseek-flash` 支持，`deepseek-v4-pro` 不支持 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)
- 思考模式：支持非思考与思考模式（默认思考） [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

### 2. 旧模型名的处理方式

- 旧模型名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可调用，但其对应模型已下线，请求将由 DeepSeek-V4.1-Flash 提供服务，并按 Flash 价格计费 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)、[2](https://api-docs.deepseek.com/zh-cn/updates)
- 官方公告：`deepseek-chat` 与 `deepseek-reasoner` 于北京时间 2026/07/24 23:59 弃用，出于兼容考虑分别对应 `deepseek-v4-flash` 的非思考模式与思考模式 [3](https://github.com/huimeicloud/hm_editor/issues/16)；第三方报道亦确认该截止日（UTC 2026-07-24 15:59）后旧名将报错 [4](https://wavespeed.ai/blog/posts/blog-deepseek-v4-model-name-migration)、[5](https://enterprisedna.co/resources/news/deepseek-api-migration-july-24-deadline-2026)
- V4 于 2026-04-24 上线预览版并同步开源，`deepseek-v4-flash`、`deepseek-v4-pro` 两个新模型名出现 [6](https://news.qq.com/rain/a/20260424A047ZK00)
