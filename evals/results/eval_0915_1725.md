# DeepSeek API 模型与定价报告（截至 2026-05-07 基准，以官方文档最新状态为准）

## 一、可用模型与规格（子问题 1）

截至官方文档最新状态，DeepSeek API 仅提供两个在售模型[1]：

| 项目 | deepseek-flash | deepseek-v4-pro |
|---|---|---|
| 模型版本 | DeepSeek-V4.1-Flash | DeepSeek-V4-Pro-0813 |
| 上下文窗口 | 1M | 1M |
| 最大输出 | 384K | 384K |
| 思考模式 | 非思考/思考，默认思考 | 非思考/思考，默认思考 |
| 图像理解（Vision） | ✅ 支持 | ❌ 不支持 |
| 并发上限 | 2500 | 500 |

两者共同支持的能力包括：JSON Output、Tool Calls、Responses API、Anthropic API、对话前缀续写（Chat Prefix Completion，Beta）；FIM 补全仅限非思考模式[1]。

访问方式：OpenAI 兼容格式为 `api.deepseek.com`，Anthropic 兼容格式为 `api.deepseek.com/anthropic`[1]。

**模型命名与退役情况（官方说明）**：`deepseek-flash` 与 `deepseek-v4-pro` 为当前规范模型名；旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍被接受，但其对应模型已退役，请求由 DeepSeek-V4.1-Flash 承接并按 Flash 价格计费[2]。官方另表示，应需求在 2026-09-14 之后继续提供 DeepSeek V4 Pro API 服务，计费方式不变[2]。旧名 `deepseek-chat` / `deepseek-reasoner` 据第三方来源称已于 2026-07-24 15:59 UTC 弃用，映射为 chat→v4-flash 非思考模式、reasoner→v4-flash 思考模式[3][4]——**该映射未经官方页面确认，仅供参考**。

## 二、官方定价（子问题 2）

单位：美元 / 1M tokens；计费量 = 输入 token + 输出 token 总和[1]。

| 模型 | 缓存命中（空闲/高峰） | 缓存未命中（空闲/高峰） | 输出（空闲/高峰） |
|---|---|---|---|
| deepseek-flash | $0.003 / $0.006 | $0.15 / $0.3 | $0.6 / $1.2 |
| deepseek-v4-pro | $0.022 / $0.044 | $0.66 / $1.32 | $1.98 / $3.96 |

- **缓存折扣**：命中价相对未命中价约为 98% 折扣（如 flash 空闲 $0.003 vs $0.15）[1]。
- **空闲时段优惠**：空闲价为高峰价的一半（50% 折扣）。这是长期计费规则，**并非限时促销**，故无到期日；高峰时段为周一至周五 UTC 01:00–04:00 与 06:00–10:00（北京时间 9:00–12:00、14:00–18:00），其余时段为空闲[1]。
- **扣费顺序**：先扣赠送余额，再扣充值余额[1]。
- **人民币计价对照**：flash 缓存命中 0.02/0.04 元、未命中 1/2 元、输出 4/8 元；v4-pro 缓存命中 0.15/0.30 元、未命中 4.5/9.0 元、输出 13.5/27.0 元（空闲/高峰）[1]。
- **重要提示**：定价页声明价格可能变动，官方保留调价权，建议定期回看定价页；且官方更新日志显示 2026-09-10 V4.1-Flash 发布当日 API 价格下调[1][5]。第三方所称「$0.14/1M 起、缓存折扣可达 98%」与官方 flash 空闲价 $0.15/1M 接近，但**应以官方定价页为准**[1]。

## 三、来源与更新时间（子问题 3）

- **定价页**：https://api-docs.deepseek.com/quick_start/pricing —— 官方 API 定价唯一权威页，未标注固定「最后更新日」，页尾声明保留调价权[1]。
- **官方更新日志**（https://api-docs.deepseek.com/updates/）的关键时间线[5]：
  - **2026-09-10**：DeepSeek-V4.1-Flash 正式发布（新架构家族最小模型，原生多模态视觉理解），API 模型名改为 `deepseek-flash`；上一代 V4 Flash 与 V4 Flash Vision Exp 退役，兼容名暂时路由至 V4.1 Flash；同日 API 价格下调。
  - **2026-08-21**：DeepSeek-V4-Flash-Vision-Exp 实验模型发布。
  - **2026-08-13**：DeepSeek-V4-Pro GA（App/Web/API，模型名 `deepseek-v4-pro`）。
- ⚠️ **日期口径提醒**：任务给定的基准日期为 2026-05-07，但官方文档与更新日志显示的最新条目（2026-08/09）晚于该基准日。本报告按「官方文档最新可查状态」呈现；若严格以 2026-05-07 为截点，则 V4.1-Flash、V4-Pro 等条目尚未发布，模型与价格须重新核对[1][5]。

## 局限说明

- 旧名 `deepseek-chat`/`deepseek-reasoner` 的退役与映射关系仅有第三方来源，未获官方页面证实[3][4]。
- 定价页未提供单独的「最后更新日期」字段，更新时点需以更新日志为参照[1][5]。

# Dify 云托管版（Dify Cloud）付费档位与价格调研报告

**访问日期：2026 年（页面已出现 gpt-5.x 模型，属较新版定价页）；币种：美元（USD），价格不含税，结账时可能另加税费。** 主要来源为 Dify 官方定价页（dify.ai），中英文页内容一致，可交叉验证。

---

## 一、档位层级总览（子问题 1）

Dify 云托管版当前官方列出 **四个层级**：Sandbox（免费）、Professional、Team、Enterprise[1][4]。

- Sandbox：免费，用于试用核心功能[1]。
- Professional：定位"独立开发者与小型团队构建生产级 AI 应用"，页面标记 "Popular/热门"[1][2]。
- Team：定位"需要协作与更高吞吐的中型团队"[1][2]。
- Enterprise：官方标价为 **"Custom/定制"**，面向需要企业级安全、合规、可扩展性、控制与定制的组织，页面无金额，属联系销售型（sales-led）[3]。

---

## 二、各付费档位公开标价与计费周期（子问题 2）

| 档位 | 月付 | 年付 | 计费周期 |
|---|---|---|---|
| Sandbox | 免费 | 免费 | — |
| Professional | $59 / 工作空间 / 月 | $590 / 工作空间 / 年（年付立省 $118） | 按工作空间订阅 |
| Team | $159 / 工作空间 / 月 | $1,590 / 工作空间 / 年（年付立省 $318） | 按工作空间订阅 |
| Enterprise | Custom/定制（无公开金额，需联系销售） | 同左 | 定制 |

- 官方英文页最新抓取确认：Professional = **$590 per workspace / year**[1]，Team = **$1590 per workspace / year**[1][2]。
- 笔记记录显示两档均提供"年付立省"（Professional 省 $118，Team 省 $318），对应月付价 $59 与 $159[4]。
- Enterprise 无公开标价，官方页仅写 "Custom"，须通过销售获取报价[3]。
- 价格按**工作空间**而非按人头计费，币种为 USD，不含税[1][4]。

---

## 三、各档位关键权益/额度差异（子问题 3）

**Sandbox（免费）**[1]：200 条消息额度；1 团队工作空间、1 成员、5 应用；50 知识库文档、50MB 知识库存储、10 次知识库请求/分钟；标准文档处理；3,000 触发器事件、每工作流最多 2 个触发器；标准工作流执行；10 条标注额度；30 天日志历史；5,000 API 限额/月[4]。

**Professional（$590/工作空间/年）**[1]：5,000 条消息额度/月；1 工作空间、3 成员、50 应用；500 知识库文档、5GB 存储、100 次知识库请求/分钟；优先文档处理；20,000 触发器事件/月、无限触发器/工作流；更快工作流执行；2,000 标注额度；无限日志历史；无 Dify API 限速。

**Team（$1,590/工作空间/年）**[1][4]：10,000 条消息额度/月；1 工作空间、**50 成员**、**200 应用**；**1,000 知识库文档**、**20GB 存储**、无限触发器事件；5,000 标注回复额度；**最高优先级处理**与优先邮件支持[4]。

**Enterprise（Custom）**[3]：企业级安全、合规、可扩展性、控制与定制；页面主体为 Community（Free）与企业版功能对比表。

**价格—权益对应关系**：从 Sandbox → Professional → Team，价格翻倍式上升（0 → $590 → $1,590/年），主要差异集中在**消息额度**（200 免费 → 5,000/月 → 10,000/月）、**成员数**（1 → 3 → 50）、**知识库文档与存储**（50 篇/50MB → 500 篇/5GB → 1,000 篇/20GB）、**触发器事件**（3,000 → 20,000/月 → 无限）及**执行优先级/日志与 API 限制**。即定价主要由席位规模、消息吞吐与知识库容量驱动[1][4]。

## 四、说明与数据局限

1. **时效性**：价格随时间和地区变化，本报告为 2026 年某时点抓取的官方标价，精确日期未能确认（页面出现 gpt-5.x 模型作为版本线索）[4]。
