模型与连接

api_key 无需填写——后端自动使用项目 .env 中配置的 key，不会经过浏览器。

messages 数组

+system +developer +user +assistant +tool(带id)
实验建议：① developer 和 system 同时放，看模型听谁的；② 构造一条 assistant(tool_calls) + 对应 tool 消息，体会回填配对；③ 故意删掉 tool 消息里的 tool_call_id 看 400 报错。

tools 参数（工具说明书，JSON 数组）

示例：天气+计算器 示例：烂描述（对比实验） 清空

请求参数

留空的参数不会出现在请求体里——发出的请求永远所见即所得。

🧠 思考模式（Thinking Mode）
