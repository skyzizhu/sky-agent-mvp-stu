## 一、产品概述

**背景**：深度调研人工耗时 2-4 小时；通用 LLM 直答三大缺陷——知识截止、多跳跑偏、编造无源。
**定位**：面向个人研究者的单用户深度研究工作台——输入问题，自主完成规划、检索、深读、笔记、验证，交付带引用的结构化报告，全程实时可视。
**设计哲学（决策依据）**：判断权在模型、执行权在代码；物理约束大于行为请求；上下文即经济学；评测即验收标准。

## 三、用户故事（US-01~06，含验收条件）

| 编号 | 用户故事 | 验收条件 |
|---|---|---|
| US-01 | 作为产品经理，我想要输入问题后自动完成检索与成文，以便压缩调研时间 | 提交后无需干预直到产出；报告含引用与参考小节 |
| US-02 | 作为审阅者，我想要看到每一步动作，以便判断结论可信度 | 执行流逐颗粒实时可见；可下钻完整 IO |
| US-03 | 作为成本敏感用户，我想要按任务规模选预算档位 | 四档可选实时显示消耗；到上限必停并交付阶段报告 |
| US-04 | 作为深度研究者，我想要同话题连续追问 | 追问轮复用笔记与上下文；检索次数较首轮降 ≥40% |
| US-05 | 作为谨慎使用者，我想要危险动作前亲自确认 | 未经确认动作执行 0 次；确认卡展示参数与原因 |
| US-06 | 作为复盘者，我想要回看任意历史研究 | 历史点击即回放；事件逐颗还原与实时一致 |

## 四、功能需求（FR-01~11）

| 编号 | 名称 | 优先级 | 优先级依据 | 异常流要点 | 验收标准 |
|---|---|---|---|---|---|
| FR-01 | 研究输入与预算档位 | P0 | 产品入口 | 空输入阻止；档位无效回落标准档 | 档位生效；仪表实时 |
| FR-02 | 自主研究循环 | P0 | 核心价值 | 规划失败降级空大纲；熔断改道；超 20 步强制结题 | 12 题全产出；重复检索去重 |
| FR-03 | 实时执行流 | P0 | 信任建立 | 心跳保活；断线续传；5 连败降级提示 | 60 秒静默不断流；不重放不漏发 |
| FR-04 | 报告交付与引用 | P0 | 最终交付物 | 内部标签净化；无报告隐藏面板 | sourced ≥ 0.90；零标签泄漏 |
| FR-05 | 动态看板核销 | P0 | 收敛保证 | 漏核销由笔记感知兜底 | 看板与模型注入同源；可追溯 |
| FR-06 | 上下文工程 | P0 | 成本曲线 | 萃取失败降级截断；压缩失败保留原历史 | 峰值不超限；事实可由笔记找回 |
| FR-07 | 安全护栏与兜底 | P0 | 交付底线 | 五出口全部进入兜底链 | 极端任务零空报告；硬收尾后零工具调用 |
| FR-08 | 危险操作人工确认 | P1 | MCP 写类工具生效 | 600 秒超时视为拒绝；拒绝回执引导改道 | 未批准动作执行 0 次 |
| FR-09 | 多轮会话 | P1 | 场景 S4 | 会话不存在优雅新建；无存档轮次占位 | 追问轮检索降 ≥40%；每轮恰记录一次 |
| FR-10 | 历史回放 | P1 | 场景 S5 | 旧格式存档优雅降级 | 回放与实时事件一一对应 |
| FR-11 | 评测回归 | P1 | 迭代基建 | 评分解析失败记 0 并标注 | 全量 30 分钟内；成绩单可对比 |

## 五、非功能需求

性能：快问 ≤3 分钟 / 标准 ≤6 分钟 / 深度 ≤15 分钟。成本：token 全覆盖记账，档位即硬上限。可靠性：15 秒心跳、断线自动重连、全量落盘可审计。安全：密钥不入库、结论强制溯源、对外动作人工确认。兼容：任一 OpenAI 兼容模型；可选 Tavily / MCP。

## 六、范围外（安全边界）

邮件投递（已实现已移除，存档 git 历史）；多租户与账号体系；agent 自我修复。**agent 会尝试执行任何未显式排除的事——本清单即安全条款。**

## 七、系统架构

四层：工作台（FastAPI+原生前端）→ 服务与评测基建 → 执行内核（依赖注入）→ 工具与配置。五出口兜底链保证交付物非空。详见 [04-AgentSpec](04-AgentSpec-编排规格.md) 与 [13-实现图纸导读](../04-交接层/13-实现图纸导读.md)。
