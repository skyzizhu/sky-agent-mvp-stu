# DeepSeek API 模型清单与最新定价（官方口径）

**信息抓取日期：2026 年（官方页面说明引至 2026-09-14；仅采信 DeepSeek 官方文档，第三方信息未采用）**

## 一、当前可用模型清单（子问题 1）

`GET /models` 接口实测返回两个模型标识，`owned_by` 均为 `deepseek`[1]：

| 模型标识 | 对应版本 | 能力模式 | 上下文长度 | 最大输出 | 视觉 |
|---|---|---|---|---|---|
| `deepseek-flash` | DeepSeek-V4.1-Flash | 非思考 + 思考（默认思考） | 1M | 384K | ✓ 支持 |
| `deepseek-v4-pro` | DeepSeek-V4-Pro-0813 | 非思考 + 思考（默认思考） | 1M | 384K | ✗ 不支持 |

- **推理/非推理**：与前代"推理模型 vs 非推理模型"分列不同，当前两个模型均为**同一模型内可切换思考/非思考模式，且默认开启思考模式**[2]。因此官方已不再单列独立的"推理模型"。
- **共同能力**：Json Output、Tool Calls、Responses API、Anthropic API、Chat Prefix Completion（Beta）；FIM Completion 为 Beta 且仅非思考模式[2]。
- **并发上限**：`deepseek-flash` 为 2500，`deepseek-v4-pro` 为 500[2]。
- **Base URL**：OpenAI 格式 `https://api.deepseek.com`；Anthropic 格式 `https://api.deepseek.com/anthropic`[2]。
- **已弃用/遗留模型名**：`deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp` 仍被接受，但对应模型已退役（retired），请求会被路由到 DeepSeek-V4.1-Flash 并按 Flash 价格计费[2][3]。

## 二、具体计费单价（子问题 2）

**单位：每 1M tokens；币种：美元 USD**[2]

| 模型 | 计费项 | OFF-PEAK（低谷） | PEAK（高峰） |
|---|---|---|---|
| **deepseek-flash** | 输入·缓存命中 | $0.003 | $0.006 |
| | 输入·缓存未命中 | $0.15 | $0.3 |
| | 输出 | $0.6 | $1.2 |
| **deepseek-v4-pro** | 输入·缓存命中 | $0.022 | $0.044 |
| | 输入·缓存未命中 | $0.66 | $1.32 |
| | 输出 | $1.98 | $3.96 |

- **时段规则**：低谷价 = 高峰价的**一半**。**高峰时段为 UTC 周一至周五 01:00–04:00 与 06:00–10:00**，其余时间为低谷时段[2]。
- **计费方式**：费用 = token 数 × 单价，优先扣减赠送余额[2]。
- **缓存命中/未命中区分**：两模型均区分缓存命中与未命中，命中输入价格显著低于未命中（如 flash 低谷 $0.003 vs $0.15）[2]。

## 三、近期变动（子问题 3）

官方 Change Log（`api-docs.deepseek.com/updates`）记录[3]：

- **2026-09-10**：正式发布 **DeepSeek-V4.1-Flash**（新架构家族中最小模型，原生多模态视觉理解）。API 模型名 `deepseek-flash` 即调用最新 V4.1 Flash；上一代 V4 Flash 与 V4 Flash Vision Exp 退役，旧模型名临时路由到 V4.1 Flash。同时页面标注 **"API pricing adjustment"**，宣布价格相应下调[3]。
- **2026-09-14**：官方决定在 2026-09-14 之后**继续提供 DeepSeek V4 Pro 的 API 服务，计费方式不变**[2][3]。
- **2026-08-21**：发布实验性多模态模型 DeepSeek-V4-Flash-Vision-Exp（`deepseek-v4-flash-vision-exp`）[3]。
- **2026-08-13**：**DeepSeek-V4-Pro GA 正式发布**（APP/Web/API），模型名 `deepseek-v4-pro`[3]。

## 结论摘要

DeepSeek API 目前官方在售模型为 **`deepseek-flash`（=V4.1-Flash，支持视觉）** 与 **`deepseek-v4-pro`（=V4-Pro-0813，不支持视觉）**，两者均支持思考/非思考双模式、上下文 1M、最大输出 384K[1][2]。定价以 USD/百万 tokens 计，分高峰/低谷（低谷为高峰半价，高峰为 UTC 周一至周五 01:00–04:00、06:00–10:00）；Flash 与 Pro 的输出价低谷分别为 $0.6 与 $1.98[2]。最新变动为 2026-09-10 发布 V4.1-Flash 并下调价格、旧 Flash 模型退役，以及 2026-09-14 后 V4-Pro 继续提供服务且计费不变[3]。

## 三、子问题 2 & 3：Professional 档的价格、计费方式与对应权益

### 3.1 价格与计费方式
- **价格：$590 / workspace / year**，币种为**美元**，计费周期为**按年**[1]。

### 3.2 消息额度机制（关键计费条件）
- 每月内置 **5,000 message credits**[1]。
