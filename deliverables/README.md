# deliverables/ —— Sky Research Agent 产品交付物全集

> **这是什么**：本项目全部产品交付物，按产品生命周期分四层编号——每个文件独立可用，编号即阅读顺序。
> **怎么找**：按你要办的事查下表「使用场景导航」；或按目录树浏览。
> **维护纪律**：代码/流程变更时，同步更新对应文档并在 15-变更日志 追加一行。
