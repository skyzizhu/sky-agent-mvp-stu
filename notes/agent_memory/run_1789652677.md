【官方 Skills 文档 learn.chatgpt.com/docs/build-skills】
- Skills = 可复用工作流的"创作格式"；Plugins = 分发渠道（含 skills + connectors/MCP），走 ChatGPT 与 Codex 共享的 universal plugin directory。
- 渐进式披露：Codex 先看 name+description，命中后才读完整 SKILL.md；初始技能列表最多占 2% 上下文窗口（未知时 8000 字符），技能太多会先缩短描述、极端情况会省略部分技能并警告。
- 目录结构：my-skill/SKILL.md（必需，含 name+description）、scripts/、references/、assets/、agents/openai.yaml（外观与依赖）。
- 触发方式：显式（ChatGPT 用 @，Codex CLI/IDE 用 /skills 或 $ 提及）+ 隐式（按 description 匹配）。
- 生成技能：ChatGPT Work 用 @skill-creator，Codex 用 $skill-creator；也可用 Record & Replay 录制流程自动生成 skill。
- 技能存放位置：REPO 级 $CWD/.agents/skills（从 cwd 逐级上溯到仓库根都扫描）、用户级 ~/.codex/skills、还有 admin/system 级；同名技能不合并、都出现在选择器里。
- Codex 会自动检测 skill 变更，不生效则重启 Codex。

【官方 Skills&Plugins 总览 learn.chatgpt.com/docs/skills-and-plugins】skill=打包指令+资源解决特定任务；plugin=可安装包，可含 skills 与 MCP servers，MCP 还能带自定义 ChatGPT UI；plugin 还可含 Codex 运行时生命周期 hooks（覆盖 ChatGPT Work 与 Codex）。选择原则：聚焦复用指令→skill；要装包+连服务→plugin。
