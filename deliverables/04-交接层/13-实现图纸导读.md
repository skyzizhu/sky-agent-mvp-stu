## 二、三条学习路径（按目的选）

**路径 A · 读懂主流程（半天）**：大节点 4（4.0 规划看板 → 4.2 主循环 → 4.3 六出口 → 4.6 硬收尾）→ 对照 README 流程图 → 工作台跑一次任务逐颗对照。

**路径 B · 读懂一次运行的数据（2 小时）**：09-数据字典的事件枚举 → 打开任意 events_{run_id}.jsonl 逐行读 → 对照 15.6 执行流颗粒。

**路径 C · 全面掌握（3-5 天）**：按大节点顺序通读，每个小节点在工作台复现一次（跑一次任务，找对应事件颗粒展开验证）。

## 三、阅读约定

- 每个小节点格式统一：**做什么 / 怎么做 / 作用与目标 / 注意**——四段齐读再动手
- ⚠P 编号 = PITFALLS.md 的坑位编号，遇到即翻阅
- 小节点编号与工作台执行流的事件编号一一对应（如 0.3 规划卡片 = 小节点 4.0 的规划节点）

## 四、修改纪律

改任何节点的实现 → 同步更新 realize.md 对应小节 → 跑评测回归 → 更新变更日志。文档与代码不一致，是这个项目最严重的债务。
