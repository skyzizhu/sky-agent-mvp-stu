# DeepSeek API 模型清单与定价调研报告

**数据来源**：DeepSeek 官方 API 文档定价页（api-docs.deepseek.com/zh-cn/quick_start/pricing）及更新日志 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

## 一、结论速览

截至 2026 年，DeepSeek 官方 API **仅提供两个在售模型**：`deepseek-flash`（V4.1-Flash）与 `deepseek-v4-pro`（V4-Pro-0813）。二者共用同一 `base_url`，均默认开启思考模式，均支持 1M 上下文与 384K 最大输出。此前的 `deepseek-chat`/`deepseek-reasoner` 命名（对应 V3.2）已不在定价页列示。

## 二、模型与参数对比

| 项目 | deepseek-flash | deepseek-v4-pro |
|---|---|---|
| 模型版本 | DeepSeek-V4.1-Flash | DeepSeek-V4-Pro-0813 |
| Base URL（OpenAI 格式） | https://api.deepseek.com | https://api.deepseek.com |
| Base URL（Anthropic 格式） | https://api.deepseek.com/anthropic | https://api.deepseek.com/anthropic |
| 思考/非思考模式 | 均支持（默认思考） | 均支持（默认思考） |
| 上下文长度 | 1M | 1M |
| 最大输出 | 384K | 384K |
| 并发限制 | 2500 | 500 |
| 图像理解 | ✅ 支持 | ❌ 不支持 |
| JSON Output / Tool Calls / 前缀续写 / FIM（非思考） | ✅ | ✅ |
| 定位 | 系列中最小尺寸、高并发、多模态 | 旗舰 |

## 三、定价对比（元 / 百万 tokens）

| 计费项 | deepseek-flash（空闲 / 高峰） | deepseek-v4-pro（空闲 / 高峰） |
|---|---|---|
| 输入·缓存命中 | 0.02 / 0.04 | 0.15 / 0.30 |
| 输入·缓存未命中 | 1 / 2 | 4.5 / 9.0 |
| 输出 | 4 / 8 | 13.5 / 27.0 |

**峰谷定价规则**：
- **空闲价 = 高峰价的 50%**，错峰调用可省一半成本。
- **高峰时段**：北京时间周一至周五 9:00–12:00、14:00–18:00；其余时段（含周末、夜间、午休）为空闲。
- 扣费顺序：优先扣**赠送余额**，再扣**充值余额**。

## 四、需注意的细节

1. **旧模型名兼容**：`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可调用，但已自动路由到 V4.1-Flash，按 Flash 计费 [1](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。
2. **历史版本参考**：2025-09-29，`deepseek-chat` 与 `deepseek-reasoner` 曾升级为 V3.2；V3.2-Speciale 为限时（至 2025-12-15）非正式部署，不支持工具调用。当前定价页已不再列示这些模型。
3. **产品选型建议**：需多模态（图像理解）或超高并发（2500）→ 选 **Flash**，且成本约为 Pro 的 1/4～1/3；需最强推理/生成质量 → 选 **V4-Pro**，并通过错峰调用压成本。

## 五、可比参考（第三方，仅供参考，可能过时）

DataCamp 教程中曾列出旧版 `deepseek-chat`（$0.07/$0.27/$1.10）与 `deepseek-reasoner`（$0.14/$0.55/$2.19，含三档价格），**未包含 V4 系列**，价格档位定义（缓存命中/未命中/输出）未获明确确认，不建议作为当前定价依据。以上金额为美元，与官方现行人民币计价口径不同，请以官方页面为准。

### 三、几个容易踩坑的规则

1. **年付立省约 17%**：Professional 年付 $590 比月付 $59×12=$708 省 $118；Team 年付 $1,590 比月付 $159×12=$1,908 省 $318 [1](https://dify.ai/pricing)。

# 阶段性结题报告：Coze（扣子）个人版与团队版订阅价格查证

> 说明：本轮因调研预算用尽提前结题。以下均来自官方文档页面（docs.coze.cn）渲染后抓取，价格为**刊例价**，官方明确「实际订购价可能因优惠活动不同，以订购界面为准」[1][2][3]。

## 一、已确认的发现

### 1. 个人版价格（月，刊例价）——来源：docs.coze.cn [1][2]

| 档位 | 价格（元/月） | 月积分 | 关键权益要点 |
|---|---|---|---|
| 个人免费版 | 0 | — | 每日登录赠送 1500 积分（有效期 1 天）；不支持创建工作空间；无插件/实时音视频/智能语音免费额度 [1][4] |
| 个人进阶版 | 39.9 | 3 万 | 图片去水印、导出剪映工程、优先通道；不支持增购积分 [1][2] |
| 个人高阶版 | 99 | 9.9 万 | 云端 Agent、可增购积分、高速通道 [1] |
| 个人旗舰版 | 199 | 19.9 万 | 项目协作者 30、云盘 20GB、极速通道 [1] |
| 个人尊享版 | 999 | 99.9 万 | 协作者 50、云盘 50GB、尊享通道、前沿模型抢先体验 [1] |

个人版共性规则：**不支持退款**；升级低→高档位立即生效、旧套餐剩余价值可按比例退（退款额=(剩余订阅积分/套餐总订阅积分)×实付金额，赠送活动积分清零）；**积分耗尽即停服，不支持超额**；积分余额连续 14 天为 0 将执行物理删除（记忆库删除不可恢复）[2]。

### 2. 团队版价格——两种官方口径（关键差异点）

**口径 A：套餐档位价（套餐与定价对比表）** [1]

| 档位 | 价格（元/月） | 月积分 | 成员数 |
|---|---|---|---|
| 团队高阶版 | 198 | 9.9 万 | 1 个起购，可增购至 50 |
| 团队旗舰版 | 398 | 19.9 万 | 1 个起购，可增购至 100 |
| 团队尊享版 | 1998 | 99.9 万 | 1 个起购，无限增购 |

**口径 B：席位单价（团队版专页）** [3]

| 档位 | 席位单价 | 每席位积分 | 席位数上限 |
|---|---|---|---|
| 团队高阶版 | 142 元/席位/月 | 9.9 万积分/个/月 | 1～50 |
| 团队旗舰版 | 283 元/席位/月 | 19.9 万积分/个/月 | 1～100 |
| 团队尊享版 | 1399 元/席位/月 | 99.9 万积分/个/月 | 1～无限增购 |

两口径关系（已可解释的部分）：团队版费用结构为「**套餐档位价 + 席位费**」并列存在——套餐档位决定权益与资源配额，**席位单独购买**，席位数决定可添加成员数，成员共享团队积分；**未开席位列自动续费时，席位价格按购买时套餐剩余有效期等比折算**（如包年套餐剩余 8.5 个月，则按 8.5 个月计收）[3]。因此 198 元/月（高阶）与 142 元/席位/月并非同一计量对象。

其他团队版规则：企业超管占 1 个席位；iOS App 购买团队版**至少 2 个成员**；团队版**不支持退款**，席位**不支持退订**；升级档位时原席位自动退订、需重新购买；已购个人版可直接买团队版，个人版剩余价值不退，两者可切换使用；账号一旦订阅过企业版，即使到期也无法再购团队版 [3]。

### 3. 多档价格差异的成因已查清（9.9/19.9/39.9 元）——来源：docs.coze.cn [4]

官方公告《扣子订阅套餐升级》明确：

- **39.9 元/月** = 个人进阶版**刊例价**（2026.1.18 新套餐上线价）[1][4]
- **9.9 元/月** = **老用户专属优惠价**（原个人进阶版或原专业版升级到个人进阶版），活动期 2026.1.19～2026.6.30，仅限首次参与，后续续费按原价 [4]
- **19.9 元/月** = **新用户自动续费首月优惠价**（连续包月），老用户首月 9.9 元；**次月 34 元**；活动期 2026.1.19～2026.3.31 [4]
- 同活动另列：个人高阶版首月 49 元/次月 89 元；个人旗舰版首月 99 元/次月 179 元 [4]
- 原团队版升级至企业标准版的老用户优惠价 **166 元/月**（默认 2 个成员，超出按实际人数计）[4]

结论：三个数字并非「个人版有多个版本」，而是**刊例价 / 老用户升级优惠 / 新用户首月自动续费优惠**三种定价场景。

### 4. 版本沿革与背景（背景信息）

2026 年 1 月 18 日新订阅体系上线，旧「团队版」调整为**企业标准版**、旧「企业版」调整为**企业旗舰版**；新增个人高阶版、个人旗舰版；「资源点」改名为「积分」；原专业版将于 2026 年 5 月 30 日下线并自动转为个人免费版；旧版套餐续费截止 2026.12.31 [4]。企业标准版 980 元起/月（34.5 万积分起），企业旗舰版 8980 元起/月（207 万积分起）[1]。
