【Cursor 官方定价·cursor.com/docs/account/teams/pricing】Teams 分两种席位：Standard $40/user/mo；Premium $120/user/mo（用量为 Standard 的 5 倍）；另有 Free $0/user/mo 的 Unpaid Admin（无 Cursor 权限）。含两个用量池：Cursor Models（Cursor Grok 4.6/4.5、Composer 2.5）与 Other Models（第三方模型），用量按席位分配、不跨成员转移、每账单周期重置。第三方模型按公开 list API 价 + Cursor Token Rate 计费；Cursor 自研模型免 Token Rate。超额走 on-demand，后付费。Enterprise 为 Custom，用量池共享（pooled），支持按成员消费限额、SCIM、发票、优先支持；大客户可联系 enterprise@cursor.com 谈量价折扣。
